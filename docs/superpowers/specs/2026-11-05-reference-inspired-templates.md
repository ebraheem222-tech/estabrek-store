# Reference-inspired editable templates

The customer supplied three local HTML examples in `addons_themes`: TemplateMo Nexus System (629), Kinetic (631), and Lantern River (634). Read their HTML, CSS and scripts as design references. Nexus uses an industrial grid, expanding image panels and tabs; Kinetic uses oversized type, a project matrix, pointer interactions and an experimental composition; Lantern River uses warm night colours, a procedural Three.js river scene and lanterns. The implementation uses original code, copy and assets, without importing their global scripts, downloaded images or fictional performance claims.

Build on the existing independent-customer CMS tree, GSAP/Anime.js options and lazy 3D stage. Preserve the existing 1,000 template IDs and add three bespoke templates (1,003 total). Every new template includes at least six editable home sections, its own typography/palette/composition and editable header/footer. Existing stores change only when their owner chooses a design or inserts a component.

Add an expanding image gallery named `showcase`, usable by every template and from the editor Add panel. Props: `items` (1–8 objects: title local(160), optional text local(1200), image safe src, href safe href, cta local(60)); optional label local(160); layout horizontal/vertical; activation click/hover; initial integer 0–7; ratio 2–6; height integer 240–800; duration seconds 0–1.5; overlay 0–0.9. Defaults: horizontal, click, initial 0, ratio 4, height 480, duration .55, overlay .5. Invalid initial values clamp to available items. Keyboard and touch can always expand panels; hover is an enhancement for fine pointers. Use proper buttons and separately focusable links, never nested interactive controls. Mobile stacks panels and prevents overflow. Reduced motion removes transitions. Editor supports item changes, reorder, images, all settings, undo and thumbnail preview.

Add a procedural built-in `lantern` 3D model to the existing stage rather than loading the downloaded scene. Expose appropriate shape knobs, colours, existing finishes and motion/light/camera controls. Keep lazy activation, reduced-motion behavior, context budget and poster fallback. No sound or autoplay audio.

Three new template IDs: `electronics-foundry`, `art-kinetic`, `home-lantern`. Use existing theme tokens with individual overrides. Both preview and installed pages use owned editable nodes, including showcase, own/local neutral artwork and existing live product blocks. New visual components remain usable independently of these templates. No dependencies, database migrations, deployment or commits are required.
