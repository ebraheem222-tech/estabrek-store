# Reference-inspired library of 2000 editable designs

The owner supplied fifteen more local TemplateMo references (576, 577, 578,
579, 582, 583, 584, 586, 587, 588, 589, 590, 591, 592, 594). Extend the
commercial, independently installed CMS with their distinct visual ideas and
reusable controls. Preserve all 1022 existing template IDs and compositions.

## Design decisions

Use native CMS trees, the existing motion runtime and original reusable
components. Do not embed uploaded HTML, execute vendor scripts, or make a
customer depend on the reference site. Directly importing static sites would
lose editor controls; changing only palettes would repeat the earlier problem
of similar templates. Author fifteen separate compositions and deterministic
reference-inspired editions whose page structures differ beyond decoration
and section order. This is an implementation choice within the owner's
existing request to develop templates and editor capabilities autonomously.

The final total is **2000**: 1022 preserved designs, fifteen new reference
designs, and 963 generated editions. Label editions clearly as generated,
retaining their source inspiration without counting them as individually
hand-authored designs. Expose curated references and generated editions as
separate discoverable collections in the same CMS picker.

## Components

- Fifteen individually composed, multilingual home pages with native editable
  headers/footers and source-specific local pictures. Retain TemplateMo
  attribution and a source manifest. Use existing animation controls, decks,
  galleries, sliders, video overlays and responsive layout where appropriate.
- A reusable `schedule` element, editable day/time/title/description/speaker/
  location/link rows, day filtering and cards/table/timeline presentations.
- A reusable `comparison` element with editable column headings and CTAs,
  highlighted plans, text/yes/no values, row headings and optional sticky header.
- Matrix-style scene decoration inspired by Nexus Flow, using bounded
  deterministic Canvas drawing and the current offscreen/reduced-motion rules.
- Generated editions composed from source visual identities, native source
  sections, independently selected structural sections and opening layouts.
  A deterministic authoring command emits inspectable recipes, seeded with
  the old designs. Reject duplicate complete/coarse trees and excessive shared
  complete sections in both preview and installed modes.
- The template picker shows the new originals first, a generated collection,
  search by source title/industry/style and actual tree previews. New originals
  receive real screenshots after browser verification. Do not reuse a source
  screenshot as the preview of a different generated edition.

## Constraints and acceptance

No new framework or animation dependency. New controls pass backend tree
validation and support the editor's undo operations. All resources stay local
to the imported customer tree; customer naming uses `{{store.name}}`. Preview
samples do not become claims about the merchant or simulated live services.
Use isolated local fixtures for tests; never modify live merchant content.
Uploaded references remain intact. Keep established hosting and deployment.

Verify exact totals, ID stability, generated structure uniqueness independently
of names/colors/images/order, asset existence, detached imports and valid trees.
Run appropriate admin/storefront/backend suites and production builds, with
browser checks of the fifteen new originals on desktop/mobile, new block
interactions, reduced motion and missing/broken media. Report any existing
typecheck issues separately and only claim deployment after inspecting it.
