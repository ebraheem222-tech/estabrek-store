# Estabrek rose design

The user rejected the initial ivory/handbag look and requested a pink design for hijab and clothing, informed by the live storefront and Admin CMS.

Use pearl-pink backgrounds, berry accents, local Cairo Arabic typography, modest campaign photography and real catalog photography. Keep product, category, cart, wishlist and search routes functional.

The published homepage controls content, section order and visibility. Simple Hero/product/collection/FAQ/CTA sections use the rose presentation. Composed components, slides, custom layouts and other section types retain the native renderer and its motion. Add optional campaign title/image/alt and 3D visibility controls to the first Hero editor, using the existing flexible JSON schema.

A procedural floating woven scarf replaces the handbag. Scroll rotates it through three chapters. Rose/lilac/pearl controls and manual rotation remain accessible. The scene is fabric inspiration. Lazy-load near the section, cap pixel ratio, pause offscreen, clean up resources and display an illustration on WebGL failure. Reduced motion or disabled CMS animation renders all chapters statically.
