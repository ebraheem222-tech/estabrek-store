# خطة المنصّة النظيفة

**الهدف:** لوحة التحكم منصّة بتعمل أي موقع، زي Figma بس مع backend وكل شي. اللي بياخد لوحة تحكم بيختار ثيم، وبيصير موقعه هالثيم وبس: متجر، موقع سيرفر، موقع تواصل، أو أي اشي تاني.

تصميم استبرق (الورد: فيلم الافتتاح، المواسم، قصة القماش، رزان، الحجاب) **ما بينحذف**. بيصير **ثيم واحد خاص باستبرق**، وبس estabrek-store.vercel.app بيلبسه. ولا متجر تاني بيشوفه أو بيوصله إشي منه، لا بالموقع ولا بلوحة التحكم.

## شو كان غلط (2026-11-24)

- **قاعدة قديمة:** أي متجر «أزياء للنساء» ما اختار ثيم كان ياخد تصميم استبرق كامل، مع رزان والحجاب. وكمان باقة «أزياء محتشمة وحجاب» بخطوات التجهيز كانت تعطي تصميم استبرق.
- **الأساس هو تصميم استبرق:** الثيمات بتلوّن تصميم استبرق. الصفحات الداخلية (المتجر، المنتج، السلة، البحث، الحساب، من نحن، تواصل، 404، الطلب، الدفع، التتبّع، المفضّلة) هي صفحات استبرق لكل المتاجر. وكل متجر بيحمّل الـ CSS تبعه (حوالي 400 KB).
  - مثال: متجر الزبون التاني (samoray1337، ثيم pc-builder، تصميمه الخاص) كانت صفحة «المتجر» عنده صفحة استبرق، وفيها «طرق أخرى لاكتشاف إطلالتكم» و«إضافة للحقيبة».
- **لوحة التحكم:** «رزان (دليلة المتجر)» بالقائمة، تبويب «تصميم روز»، أمثلة بالمربّعات عن الحجاب، نوع منتج «ملابس» (شيفون، كريب، صلاة، رمضان والعيد)، و«بمساعدة رزان 🌸» بالطلبات.

## المراحل

### 0. حفظ نسخة اليوم ✅ (2026-11-24)
- **الكود:** علامة git اسمها `estabrek-design-2026-11-24` على main (856a9624). بترجّع التصميم زي ما كان بأي وقت.
- **إعدادات المتجر وصفحاته:** `docs/estabrek-theme/2026-11-24/`، من الـ API العام:
  - `bootstrap.json`: الإعدادات والقوائم والهيدر.
  - `home-page.json`: الصفحة الرئيسية بفصولها.
  - `pages.json`: الصفحات.
- **الصور:** `shots/` فيها 18 صفحة من الموقع الحي، كمبيوتر وموبايل.

### 1. ثيم استبرق الخاص
- **الثيم:** تصميم الورد صار ثيم اسمه `rose`.
  - المتجر بيلبسه بس إذا اختاره (`header.storeTheme = {"id":"rose"}`).
  - بيطلع بمعرض الثيمات بس للمتجر اللي بيملكه (`header.privateThemes`)، وباسم المتجر نفسه («تصميم استبرق»).
  - لما متجر تاني يحاول يحفظه، الحفظ بينرفض.
- **ولا إشي بيرجع لتصميم استبرق:**
  - متجر ما اختار ثيم بياخد ثيم نوعه من المكتبة.
  - قاعدة «أزياء نساء = استبرق» انشالت.
  - باقة الحجاب بالتجهيز صارت تعطي `silk-veil` وكلام إلها.
- **رزان وكلام استبرق صاروا مربوطين بالثيم، مش بنوع المتجر:**
  - العنوان والوصف وصورة المشاركة، وكلام الهيدر والفوتر ومن نحن.
  - «عالم الأقمشة» وفيلم الحرير.
- **لوحة التحكم:**
  - «رزان» بتطلع بس لمالك الثيم.
  - تبويب «تصميم روز» صار «واجهة المتجر» (فيه إعدادات عامة).
  - ألوان مشاهد الرئيسية بتطلع بس للي لابس الثيم.
  - مثال وصف المتجر صار عام.
- **migration:** `20261124090000_rose_theme` بتكتب الثيم على متجر استبرق بس، فبيضل شكله نفس الشي.
  - لازم تنزل على الـ API **قبل** كود المتجر الجديد. لهيك بتروح بـ PR لحالها أول.

### 2. أساس نظيف
- **صفحات محايدة لكل المتاجر:** الهيدر، الفوتر، المتجر، المنتج، السلة، الدفع، البحث، الحساب، من نحن، تواصل، 404، الطلب، الدفع، التتبّع، المفضّلة.
  - كلامها عام («السلة» مش «الحقيبة»، بلا «إطلالة»).
  - بتاخد ألوانها وخطوطها وأشكالها من الثيم مباشرة، بلا تلوين تصميم استبرق.
- **الـ CSS:** تبع استبرق (cinematic + rose-*) بينحمّل بس مع ثيم استبرق.

### 3. كل ثيم بيلبّس الموقع كله
- كل ثيم بيعطي شكله لكل الصفحات: البطاقة، صفحة المنتج، السلة، الهيدر والفوتر.
- اللي بتختاره هو اللي بتشوفه.

### 4. لوحة التحكم بتتبع نوع الموقع
- **موقع سيرفر:** بيشوف سيرفراته وقوانينه وتقديماته.
- **موقع تواصل:** بيشوف أعضاءه ومنشوراته.
- **المتجر:** بيشوف المنتجات والتوصيل.
- **أشياء استبرق ما بتطلع لحدا تاني:** الكويز بأزياء رزان، الطلبات الخاصة بكلام الحجاب، ونوع «ملابس».

### 5. فحص
- تست بيمرق على كل صفحات الموقع ولوحة التحكم بثيم تاني.
- بيفشل إذا لقى «حجاب» أو «رزان» أو أي class من تصميم استبرق.

الموجة 2 من خطة الـ 300 موقع (ثيمات المواقع) بتستنّى لبعد المرحلة 3، لأنها بتنبني على الأساس النظيف.
