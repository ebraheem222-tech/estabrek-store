# خطة المحرّك الكبير للـ CMS

خطة، ولا شي منها مبني لسا (2026-11-12). كل خطوة رح تكون PR لحالها مع تجاربها.

## شو موجود هلأ

- **المجموعات:** 9 أنواع حقول (نص، نص طويل، صورة، رقم، تاريخ، رابط، نعم/لا، اختيار، لون). القيم محفوظة كـ JSON. ما في علاقات بين الجداول.
- **الاستوديو:** تحديد العناصر، وزر «تكبير على المحدد».
- **لوحة الـ SVG:** بتغيّر الألوان واحد واحد وعرض الخط. ما بتحدد جزء من الرسمة.
- **صفحة الفيديو:** غلاف من كادر، تحويلات، قص للتلفون. ما فيها timeline. التحويل الواحد بيطلع كـ Cloudinary أو ffmpeg، والمهام بغرفة المهام.
- **أحداث العناصر:** فيه أحداث وأفعال (burst، صوت…). محرك «لما ← إذا ← اعمل» نصّه مبني على فرع feat/recipes-engine.
- **مكتبات جاهزة بالمتجر:**
  - GSAP 3.13 ومعه MorphSVG وDrawSVG وMotionPath، كلهم مجانيين من 2025.
  - Tailwind 3.4 بالمتجر والأدمن.
  - sharp بالمتجر والباك اند.
- **الباك اند:** Express 5، Prisma 6 (89 جدول)، zod 4، Postgres على Neon.

## المسار A: وضع التركيز، ومحرّر لكل نوع

### A1. القشرة
دبل كليك أو زر «تحرير» على أي عنصر:
- الكانفس بيعمل zoom ناعم عليه، والباقي بيغمق.
- مسار فوق: الصفحة › القسم › العنصر › الجزء.
- على الجنب شجرة أجزاء، ولوحة تحكم بتتبدّل حسب الجزء المحدد.
- Esc بيرجع خطوة، والتراجع سجل واحد.
- كل نوع بيسجّل محرّره بنفس القشرة: svg، صورة، فيديو، 3D، نص، شكل، سلايدر، فورم…

### A2. SVG بالأجزاء
- الرسمة بتتفكك لأجزاء بأسماء: مجموعات، مسارات، نصوص.
- تحديد جزء بيفتح أدواته:
  - تعبئة: لون، أو تدرّج، أو ربط بلون من الثيم.
  - خط، شفافية، إخفاء.
  - تحريك وتدوير وحجم للجزء لحاله.
  - تعديل نقاط المسار (bezier).
- حركة للجزء:
  - رسم الخط (DrawSVG).
  - ظهور ومشي على مسار (MotionPath).
  - keyframes من محرك الحركة الموجود.
- hover وclick للجزء، عن طريق المحرك (D).

### A2+. تحوّل SVG لشكل تاني (morph)
- بتختار «تحوّل إلى…» على رسمة أو جزء. الشكل الهدف بيجي من:
  - مكتبة الأيقونات أو الرسومات.
  - SVG بترفعه.
  - رسمة بترسمها.
- متى بيتحوّل:
  - hover.
  - click ذهاب وإياب، متل ☰ ← ✕، ▶ ← ⏸، ♡ ← ♥.
  - scroll بيتبع القسم.
  - سلسلة A ← B ← C بلفّة.
  - تغيّر حالة أو متغيّر.
- المحرك هو MorphSVGPlugin، وهو أصلاً بالمتجر:
  - بيتعامل مع عدد نقاط مختلف.
  - `shapeIndex: auto`.
  - `convertToPath` للدواير والمستطيلات.
- رسمة فيها كذا جزء:
  - الأجزاء بتتطابق زوج زوج (بالترتيب، أو بالاسم، أو بالمساحة).
  - اللي بيزيد بيختفي أو بيصغر.
- اللون والخط والتدرّج بيتحوّلوا مع الشكل.
- بتتحكم بالمدة والـ easing والفرق بين الأجزاء.
- بينحمّل بس بالصفحات اللي فيها morph (lib/earlyPart.ts).
- مع «تقليل الحركة» بيصير تلاشي بسيط.

### A3. محرّر الصور
- قص وتدوير وقلب، ونسب جاهزة (مربع، 4:5، 9:16، بانر)، ونقطة التركيز.
- إضاءة، تباين، تشبع، حرارة، حدّة، وفلاتر جاهزة.
- إزالة الخلفية (الموجودة).
- طبقات نص وملصقات وأشكال.
- غير مدمّر: الأصل محفوظ والتعديل وصفة. الإخراج بكل المقاسات من sharp أو Cloudinary.

### A3+. نجوم براقة على حواف الصورة وزواياها
بترفع صورة، والمحرّر بيلاقي الحواف والزوايا والنقاط اللامعة، وبيرسم عليها نجوم بتلمع.

**التحليل:** مرة وحدة بالأدمن، مش على تلفون الزبون:
- بيصير بـ Web Worker:
  1. رمادي.
  2. تنعيم خفيف.
  3. زوايا (Harris أو FAST) وحواف (Sobel أو Canny) ونقاط الإضاءة العالية.
  4. تنقيط كل نقطة، واختيار N نقاط موزّعة بمسافة بينها.
- ممكن يقتصر على المنتج بقناع إزالة الخلفية، فما بيطلع نجوم عالخلفية.
- النقاط بتنحفظ كنِسَب (0–1) مع الصورة، فبتضل بمكانها بأي مقاس.

**الرسم بالمتجر:**
- طبقة خفيفة فوق الصورة: نجمات SVG أو CSS، وcanvas إذا كانوا كتار.
- كل نجمة إلها توقيت لحالها، فما بيلمعوا كلهم سوا.
- الحركة transform وopacity بس.
- بتوقف برّا الشاشة ووقت السكون (pageIdle).

**التحكم:**
- العدد، الحجم من–لـ، اللون (أبيض، ذهبي، من الثيم، من الصورة).
- الشكل: 4 رؤوس، 6 رؤوس، وهج دائري، صليب مع أشعة.
- سرعة اللمعة والعشوائية.
- المنطقة: زوايا، حواف، لمعات، المنتج كله.
- متى: دايماً، hover، لما تظهر، مرة وحدة.
- بوضع التركيز: كبسة بتزيد نجمة، سحب بينقلها، وكبسة تانية بتشيلها.
- كمان على SVG، لأنه نقاطه معروفة بالزبط، وعلى زوايا الحروف بالنص.

### A4. محرّر الفيديو (صفحة كاملة)
- timeline بمسارات: فيديو، صور، نص، صوت.
- قص وتقسيم وحذف، وترتيب بالسحب، وسرعة وانتقالات.
- نصوص متحركة بخطوط الثيم، موسيقى وكتم، تلوين بسيط، قص للتلفون أو مربع، غلاف.
- المعاينة حيّة بالمتصفح. الإخراج النهائي على السيرفر بخط التحويل الموجود (MP4 + HLS)، مع شريط تقدّم بغرفة المهام.
- بينحفظ كمشروع بترجعله وبتعدّله.

### A5. محرّر الـ 3D
- أجزاء الموديل، ولكل جزء لون ومادة وخشونة ولمعان وصورة.
- زوايا كاميرا محفوظة، إضاءة وبيئة، وحركات الموديل.
- نقاط تعريف (hotspots) عليها نص.
- ضغط Draco للسرعة.

### A6. باقي الأنواع
نص على مسار، أشكال، سلايدر شريحة شريحة، فورمات. كلهم بيدخلوا نفس القشرة.

## C. CSS لكل عنصر (Tailwind أو CSS عادي)

- بكل عنصر تبويب «CSS» بنمطين:
  1. **Tailwind:** كلاسات مع إكمال تلقائي وشرائح.
  2. **CSS عادي:** محرّر كود مع إكمال للخصائص ولمتغيّرات التصميم (W2).
- الـ CSS بيتقيّد بالعنصر تلقائياً:
  - بتكتب خصائص، أو قواعد متداخلة: `&:hover {…}`، `& .part {…}`.
  - بتتحوّل لـ `[data-pt="id"] …`، فما بتأثّر على غير عناصر.
- حالات جاهزة: hover، focus، ضغط، تلفون/تابلت/كمبيوتر، داكن، بعد الـ scroll، لما متغيّر يساوي قيمة.
- **Tailwind بينبنى على السيرفر وقت الحفظ:**
  - بـ API الـ node تبع Tailwind، والمحتوى هو الكلاسات نفسها.
  - ألوان الثيم بتصير ثيم Tailwind، يعني `bg-primary` = لون المتجر.
  - الـ CSS الناتج بينحفظ مع الصفحة. المتجر ما بيحمّل Tailwind بوقت التشغيل.
- **الأمان والتحقق:**
  - الـ CSS بينقرا بمحلّل (postcss).
  - بينرفض: `@import`، و`url()` من برّا مكتبة الوسائط، وأي شي خطير.
  - في حد للحجم، والأخطاء بتبين بنفس السطر.
  - المعاينة حيّة بالاستوديو.
- **بينحفظ ستايل:** «ستايل زر» أو «ستايل كرت» بمكتبة التصميم، بينطبّق على كذا عنصر.
- **الأولوية:** اللوك من اللوحات أول، والـ CSS الخاص بيغلب. اللوحة بتورجيك شو انغلب.

## D. أحداث العناصر وأفعالها، مع تحقق وصلاحيات

هاد هو محرك «لما ← إذا ← اعمل» (feat/recipes-engine)، بعد ما نكبّره.

**الأحداث:**
- كبسة، دبل كبسة، ضغط مطوّل.
- دخول وخروج الماوس.
- ظهور عالشاشة، أو مرور نسبة من الـ scroll.
- إرسال فورم أو تغيّر قيمة.
- مؤقّت، فتح الصفحة، زر بالكيبورد.

**الأفعال:**
- روح لصفحة: داخلية، منتج، تصنيف، رابط برّا، رجوع، أو مكان بنفس الصفحة.
- فتح popup أو درج.
- تشغيل أو إيقاف فيديو، أو تشغيل حركة.
- تغيير حالة أو متغيّر.
- إضافة للسلة أو المفضلة، أو تطبيق كوبون.
- نسخ نص، مشاركة، اتصال، واتساب، تنزيل ملف.
- إرسال فورم.
- **تشغيل function على السيرفر** (B5).
- رسالة (toast).

**قبل الفعل (الشروط):**
- التحقق من الفورم: قواعد لكل حقل، ورسائل بالعربي والعبري والإنجليزي.
- شروط: مسجّل دخول، مجموعة زبائن، مجموع السلة، الوقت، اللغة، الجهاز، متغيّر.
- نافذة تأكيد: «متأكد؟».

**مين مسموحله:**
- الكل.
- زبون مسجّل.
- زبون اشترى منتج معيّن.
- موظف بدور أو صلاحية معيّنة.
- الشرط بينطبّق مرتين:
  1. بالمتجر الزر بيختفي أو بيتقفّل. هاد للشكل بس.
  2. **على السيرفر** أي شي بيغيّر بيانات بينفحص هناك (الجلسة، الدور، المفتاح). هاد هو الحماية الحقيقية.
- حد للطلبات، وحماية من السبام.

**بعد الفعل:**
- فرع نجح وفرع فشل: رسالة، روح لصفحة، أو غيّر متغيّر.
- الزر بيصير «عم يحمّل» ومقفول، فما بتنكبس مرتين.

**السجل:** مين شغّل شو، وإيمتا، وشو صار. بيبين بسجل الأدمن.

## المسار B: استوديو البيانات (الباك اند)

### B1. الجداول
- شبكة متل Airtable: فلترة، ترتيب، بحث، صفحات، تعديل بالخلية، تعديل جماعي.
- استيراد وتصدير Excel/CSV، ومسودة ومنشور.
- جداول المتجر الأساسية (منتجات، طلبات، زبائن، تصنيفات) للعرض بس.

### B2. الـ schema
- جدول جديد وحقول بأنواع أكتر:
  - نص غني، عملة، تاريخ ووقت، إيميل، تلفون.
  - ملف، فيديو، موديل 3D، JSON.
  - اختيار متعدد، موقع عالخريطة، حقل محسوب، slug تلقائي.
- لكل حقل قواعده: إجباري، فريد، قيمة افتراضية، حدود، نمط، ورسالة خطأ بالعربي والعبري والإنجليزي.
- لما تغيّر نوع حقل بتشوف كيف رح تتحوّل البيانات قبل ما تطبّق.
- كل تغيير بالـ schema إله نسخة وبترجع عنه.

### B3. العلاقات
- واحد-لواحد، واحد-لكثير، كثير-لكثير. بين جداولك، وبين جداولك وجداول المتجر.
- مخطط بصري (ER): بتسحب خط بين حقلين لتعمل علاقة.
- عند الحذف بتختار: بينحذف معه، بينفك الربط، أو بينمنع.
- بالشبكة بتختار السجلات المرتبطة من نافذة بحث.

### B4. API تلقائي
- لكل جدول endpoints جاهزة:
  - قائمة، مع فلترة وترتيب وصفحات وجلب المرتبط.
  - سجل واحد، إضافة، تعديل، حذف.
- التحقق zod مبني تلقائياً من الـ schema نفسه.
- صلاحيات لكل جدول ولكل عملية: عام، زبون (سجلاته بس)، موظف بدور.
- مفاتيح API، حد للطلبات، وثائق OpenAPI تلقائية، وصفحة بتجرّب فيها الطلبات من الأدمن.

### B5. endpoints خاصة
- بتعرّف route: المسار، الـ method، المدخلات، قواعد التحقق، والصلاحية.
- خطواته بمحرك (D) شغّال على السيرفر: استعلام، حساب، كتابة، إيميل أو واتساب، والرد.
- webhooks لما يتغيّر سجل، ومهام مجدولة.

### B6. الربط مع الصفحات
- أي عنصر بينربط بجدول أو حقل، كمان عبر العلاقات (منتج ← تقييماته).
- فلترة وترتيب بالربط.
- فورمات الموقع بتكتب بجدول مباشرة بنفس قواعد التحقق.

**الحماية:**
- جداول المتجر الأساسية ما بتنحذف ولا بيتغيّر شكلها من هون.
- كل شي بينكتب بسجل التدقيق.
- نسخة احتياطية قبل أي تغيير كبير بالـ schema.

## F. مكتبة الحيل (tricks)

بحثت بـ Google ومواقع روسية (Habr) وreddit (r/css) وCodrops وweb.dev وChrome وSmashing. المكتبة بتكبر مع كل مرحلة:
- كل حيلة بتصير **إعداد جاهز** بلوحة (اللوك، الحركة، الحيل)، مع مقابض بسيطة.
- الكود بنكتبه إحنا، مش منسوخ من حدا.
- لكل حيلة بديل للمتصفحات اللي ما بتدعمها، وبديل لـ «تقليل الحركة».

### 1. حواف وأزرار
- **حافة متدرّجة بتلف:** `conic-gradient` بزاوية مسجّلة بـ `@property` بتتحرّك. مقابض: الألوان، السرعة، العرض.
- **لمعة بتمرق عالزر:** شريط مائل بيمشي بـ hover أو كل كم ثانية.
- **زجاج:** `backdrop-filter` مع حافة فاتحة وظل.
- **زوايا بأشكال:** `corner-shape` (squircle، notch، scoop، bevel). شكل حر بـ `shape()`، وبديل `border-radius`.
- **زر سائل (gooey):** blur وcolor-matrix بفلتر SVG.
- **زر مغناطيسي:** بيلحق الماوس شوي (JS خفيف).
- **موجة عند الكبسة (ripple)**، **زر ثلاثي الأبعاد بينضغط**، **توهّج نيون**.

### 2. نصوص
- **نص متدرّج:** `background-clip: text`. ومتحرّك بـ `@property`.
- **نص مفرّغ:** `-webkit-text-stroke` مع تعبئة شفافة. فيه كمان حافة متدرّجة.
- **نيون:** ظلال فوق بعض، مع وميض عشوائي.
- **glitch:** نسخ من النص بتنزاح وبتنقصّ.
- **موجة وزن:** الخطوط المتغيّرة (`wght`) حرف حرف، مع تأخير بـ `sibling-index()`.
- **آلة كاتبة**، **فك تشفير (scramble)**.
- **نص بيتعبّى مع الـ scroll:** خلفية النص بتمشي على scroll timeline.
- **نص على مسار** (`textPath`)، و**قصّ فراغ النص** (`text-box-trim`) لمحاذاة دقيقة.

### 3. صور وأقنعة
- **كشف بـ clip-path:** دائرة من نقطة، مسح مائل، أو inset لما تظهر.
- **حواف بتتلاشى:** `mask-image`.
- **كشّاف بيلحق الماوس:** قناع دائري عند الماوس.
- **صورتين بالـ hover:** التانية بتنكشف بشكل.
- **لونين (duotone)**، **حبيبات (grain)** بـ `feTurbulence`.
- **تشويه بالـ hover:** `feDisplacementMap`.
- **Ken Burns**، **قبل وبعد**، **ميلان ثلاثي الأبعاد مع لمعة** بتلحق الماوس.
- **طبقات parallax:** `translateZ` أو scroll timeline.

### 4. scroll
- **حركات مربوطة بالـ scroll:** `animation-timeline: view()/scroll()`، لظهور وشريط تقدّم وparallax وكروت فوق بعض. فيه بديل لـ Firefox.
- **حركات بتنطلق عند نقطة scroll** (scroll-triggered، جديد بـ Chrome).
- **شكل حسب حالة الـ scroll:** `scroll-state`. الهيدر لما يلزق، أو الشريحة الملقوطة.
- **سلايدر CSS بالكامل:** `::scroll-marker` للنقاط و`::scroll-button()` للأسهم.
- **قسم بيمشي عالجنب**.

### 5. منطق وتخطيط
- **حالة الأب من الابن:** `:has()`، متل كرت بيتغيّر لما تختار لون.
- **container queries**، **anchor positioning** لـ tooltip ونقاط المنتج.
- **دواير وتأخير:** `sibling-index()` و`sibling-count()` مع sin وcos.
- **شروط وfunctions:** `if()` و`@function`، و`attr()` بأنواع (لون من data attribute).
- **فتح لارتفاع auto:** `interpolate-size` أو `grid-template-rows: 0fr ← 1fr`.
- **قائمة اختيار بشكلنا:** `appearance: base-select`، `::picker(select)`.
- **popover وأزرار أوامر بلا JS**.
- **نقل عنصر بدون ما يخسر حالته:** `moveBefore`، لفيديو شغّال مثلاً.

### 6. انتقالات
- **View Transitions بين الصفحات:** `@view-transition`. صورة الكرت بتتحوّل لصورة صفحة المنتج.
- **مجموعات متداخلة** للـ 3D والقص، و**تلاشي هادي** مع «تقليل الحركة».

### 7. SVG
- **رسم الخط:** DrawSVG أو `stroke-dashoffset`.
- **التحوّل:** MorphSVG.
- **مشي على مسار:** MotionPath.
- **سائل:** gooey.
- **مرسوم باليد:** فلاتر turbulence بتتبدّل.
- **تشويه سائل**، **تعبئة بنقشة**، **تدرّجات متحركة**.

### 8. ضوء وجزيئات
- **نجوم براقة على الزوايا** (A3+).
- **لمعة بتمرق**، **bokeh**، **قصاصات (confetti)** (موجودة).
- **حقل نجوم:** كل نجمة إلها توقيتها، وأشعة للامعة منها.
- **أثر الماوس**، **كشّاف**.

### 9. ألوان
- **تدرّجات وmesh متحركة:** `@property`.
- **خلط وألوان نسبية:** `color-mix` و`oklch(from …)`، مستعملين أصلاً.
- `light-dark()`، **blend modes**.

### 10. سرعة ووصول
- الحركة `transform` و`opacity` بس.
- `content-visibility` و`will-change` بحساب.
- `@supports` للبدائل، و`prefers-reduced-motion`.
- كل حيلة بتوقف برّا الشاشة ووقت السكون.

**المواقع اللي رح تبعتها:** بدرس كل موقع، وبطلّع منه الحيل كأفكار، وبنبنيها بشكلنا الخاص. ما بننسخ تصميم حدا.

## G. شكل كل عنصر بالمعادلات: كل زاوية وكل جهة لحالها

بوضع التركيز على أي عنصر (صورة، كرت، زر، قسم، فيديو) بتطلع **مقابض على الـ 4 زوايا والـ 4 جهات**، وكل وحدة بتتحكم فيها لحالها.

**كل زاوية لحالها** (فوق يمين، تحت يمين، فوق يسار، تحت يسار):
- **دائرية:** نصف قطر أفقي وعامودي، فممكن تكون بيضاوية.
- **squircle:** superellipse بأُس n، من مربع لدائرة لأي شي بيناتهم.
- **مشطوفة (bevel)**.
- **مقصوصة لجوّا (notch)**.
- **مقعّرة (scoop)**.
- **Bézier حرّة:** بمقبضين.

**كل جهة لحالها:**
- مستقيمة.
- منحنية لبرّا أو لجوّا: Bézier تربيعي أو تكعيبي، بمقابض بتشوفها وبتسحبها.
- قوس.
- **موجة** sin: الارتفاع، الطول، والطور. الطور بيتحرّك، فالحافة بتتموّج.
- أسنان (zigzag)، أو أقواس متكررة (scallops).
- **معادلة بتكتبها:** `y = f(x)` مع sin، cos، pow، abs، exp، noise…، بمحلّل رياضي آمن.

**الشكل كله بمعادلة:**
- superellipse: `|x/a|ⁿ + |y/b|ⁿ = 1`.
- منحنيات قطبية `r(θ)`: وردة، نجمة، فقاعة.
- blob بـ noise.

**بالكانفس:**
- سحب للمقابض، والتصاق (snapping).
- **قفل تماثل:** يمين مع يسار، أو الزوايا الأربعة سوا.
- قيم لكل جهاز.

**كيف بينرسم:**
- الشكل البسيط بيستعمل `corner-shape` الأصلي، فالحافة نظيفة.
- الشكل المعقّد بيصير مسار `clip-path: shape()`، بنِسَب فبيكبر ويصغر مع العنصر. البديل `path()` أو قناع SVG.
- الحافة والظل:
  - طبقة SVG بنفس المسار بترسم الحافة.
  - `drop-shadow` على الغلاف بيعمل الظل.
  - لأنه clip-path بيقص الـ border والـ box-shadow.

**الحركة:**
- الشكل بيتحرّك بين حالتين بالـ hover أو الـ scroll.
- الحركة بالمعاملات (نصف القطر، الأُس، الموجة)، مش بالمسار، فبتضل ناعمة دايماً.
- **فواصل الأقسام** بموجة أو منحنى من نفس المحرّر.

## H. منحنيات الحركة وكل المعادلات

**محرّر easing:**
- **cubic-bezier** بمقبضين بتسحبهم، وكرة بتورجيك الحركة حيّة.
- **steps()**.
- **spring:** الكتلة، الصلابة، الاحتكاك، والسرعة الأولى.
- **bounce** و**elastic**.
- **معادلة بتكتبها** `f(t)`.
- **منحنى بترسمه بإيدك**.

**مكتبة المعادلات:** sine، quad، cubic، quart، quint، expo، circ، back، elastic، bounce، كل وحدة in وout وinOut.

**بدون JS وقت التشغيل:**
- الـ spring والمعادلات والمنحنى المرسوم بيتحوّلوا لـ CSS `linear()` بنقاط كتير.
- فالحركة بتنحسب وقت الحفظ، مش على تلفون الزبون.

**وين بينطبّق:** الدخول، الـ hover، الـ scroll، الـ keyframes، الـ morph، انتقال الصفحات. بينحفظ كمتغيّر تصميم، يعني «حركة البراند».

**مسار بمعادلة:**
- العنصر بيمشي على `x(t), y(t)`: دائرة، ∞ (lemniscate)، Lissajous، حلزون، موجة.
- أو على Bézier بترسمه (MotionPath).
- منيح للزينة اللي بتدور حوالين المنتج.

## I. محرك فيزياء كامل

### I1. فيزياء لعنصر واحد (خفيفة، بدون محرك)
- **نابض بيلحق:** الماوس، الـ scroll، أو عنصر تاني.
- **رمي وانزلاق:** بتسحب وبتفلت، وبيكمل لحاله لحد ما الاحتكاك يوقفه.
- **نطّة عند الوقوع**.
- **بندول:** متل بطاقة سعر معلّقة بتتمرجح.
- **مغناطيس**.
- **جيلي:** squash and stretch.
- **طفو**.

بتنحسب بمعادلات مغلقة أو integrator صغير. واللي بيتكرر بيتحوّل لـ `linear()`.

### I2. عالم فيزياء لقسم كامل
- **العناصر بتصير أجسام:**
  - ثابتة أو متحركة.
  - شكلها مربع، أو دائرة، أو مضلّع ماخد من شكل العنصر أو حدود الـ SVG.
- **مقابض لكل جسم:** الكثافة، الاحتكاك، الارتداد، ومقاومة الهوا.
- **الجاذبية:** اتجاهها وقوتها. على التلفون ممكن تمشي مع ميلان الجهاز.
- **الحدود:** القسم، أرض، حيطان.
- **الروابط:** نابض، حبل أو سلسلة، مفصلة، موتور.
- **القوى:**
  - ريح.
  - انفجار عند الكبسة.
  - جاذب عند الماوس.
- **التفاعل:**
  - السحب والرمي بالماوس أو الإصبع.
  - صوت أو burst عند التصادم.
  - **«لما جسم يفوت منطقة» ← فعل** بمحرك (D).
- **أمثلة:**
  - المنتجات بتوقع بسلة مع الـ scroll.
  - حروف العنوان بتوقع وبتتكوّم.
  - فقاعات التصنيفات بتتدافش.
  - بطاقات معلّقة بحبال.
- **قماش وحبال ناعمة:** solver صغير من نوع Verlet، منيح لطرف حجاب أو شريط.

### I3. 3D
فيزياء جوّا مشاهد الـ 3D الموجودة (R3F) بـ Rapier.

### I4. بالاستوديو
- زر ▶ «شغّل» بوضع التركيز، ومؤشر بترجع فيه، وإعادة.
- بتحدّد مواقع البداية.
- **«احفظها كحركة» (bake):** المحاكاة بتنسجّل keyframes، فوقت التشغيل ما في أي حساب فيزياء.

### I5. السرعة
- المحاكاة بخطوة ثابتة (60Hz) مع تنعيم، وممكن بـ Web Worker.
- الأجسام الواقفة بتنام.
- بتوقف برّا الشاشة، وبالتبويب المخفي، ووقت السكون.
- الـ DOM بيتحرّك بـ transform بس.
- في حد لعدد الأجسام، وعالتلفون أجسام أقل وخطوة أبطأ.
- مع «تقليل الحركة» بيبين الشكل النهائي ثابت.
- المحرك بينحمّل بس بالصفحات اللي فيها فيزياء (earlyPart).

## J. مركز التحكم بالسرعة (GPU والأداء)

**موجود بالأدمن هلأ:**
- إعدادات حركة على مستوى الموقع: سقف الإطارات 30–120، تكيّف، خفيف مع توفير البيانات، زجاج عالتلفون، تحميل الفيديو.
- مراقبة السيرفر: الـ routes، الاستعلامات، المسارات.
- قياس الزبائن الحقيقيين (RUM).

### J1. إعدادات سرعة لكل صفحة ولكل عنصر
- **الجودة:** كاملة، متوازنة، أو خفيفة.
- **سقف الإطارات**.
- **وقف برّا الشاشة**، شغّال افتراضياً.
- **وقف وقت السكون**.
- **نسخة للتلفون:** تأثير أخف، أو بدونه.
- **«بس عالأجهزة القوية»:** حسب الذاكرة والمعالج ونوع كرت الشاشة.
- **تخفيف تلقائي:** مع توفير البيانات أو البطارية الضعيفة.

### J2. عدّاد كلفة بالاستوديو
- كل عنصر عليه شارة: أخضر، أصفر، أحمر. شو الغالي فيه:
  - blur أو backdrop-filter، وفلاتر على مساحة كبيرة.
  - ظلال كبيرة.
  - حركة بلا نهاية.
  - canvas أو 3D.
  - فيديو.
  - أجسام فيزياء أو جزيئات كتير.
- **ميزانية للصفحة كلها:**
  - حجم الـ JS.
  - الطبقات التقيلة.
  - الحركات اللي شغّالة وقت السكون.
  - الإطارات بالثانية.
- بيتقاس حيّ بإطار المعاينة (long tasks وLoAF وعدد الطبقات)، ومع قواعد بتقرا الستايلات.

### J3. التحسينات التلقائية
هي نفسها اللي عملتها بإيدي، بس بتصير مبنية بالمحرك:
- الحركة بتوقف برّا الشاشة ووقت السكون.
- الحركة اللي بلا نهاية بتصير محدودة.
- الحركة اللي بتعيد الرسم بتتحوّل لـ transform وopacity.
- `will-change` بينضاف وبينشال تلقائياً.
- الأجزاء التقيلة بتنحمّل بس وين بتلزم (earlyPart).
- الـ 3D على 30 إطار وقت السكون.
- الـ hover بيوقف أثناء العجلة.
- المشاهد بتنبنى بوقفات الـ scroll.
- الصور بمقاسات مناسبة، وسياسة لتحميل الفيديو.

### J4. «صلّحها»
تقرير لكل صفحة:
- **الأرقام:** التحميل، وقت التعليق (TBT)، أكبر رسمة، الإطارات بالـ scroll، والـ GPU وقت السكون.
- **اقتراحات بكبسة وحدة:**
  - «خفّف الـ blur عالتلفون».
  - «وقّف هاي الحركة».
  - «احفظ الفيزياء كحركة».

### J5. فحص قبل النشر، وتنبيهات
- **قبل النشر:** قياس على السيرفر، متصفح مخفي ومعالج مبطّأ 4 مرات.
- **إذا الصفحة طلعت فوق الميزانية:** تحذير قبل النشر.
- **بعد النشر:**
  - إذا الزبائن الحقيقيين صارت الصفحة عندهم أبطأ، بيطلع تنبيه.
  - مع اقتراح ترجع للنسخة القديمة.
